# 角色面向编码于空间旋转

角色的左右面向会在移动、演出及原地交互中改变，玩家读档后也应保持保存时的面向。由 `CharacterMotorAbility` 统一改变角色 Root 的旋转，以 Y 轴半周旋转表示相对默认朝左的镜像；完整旋转写入 `SpatialState.Rotation`，沿用现有玩家存档和恢复路径。

## 备选方案

- 只翻转角色的视觉子物体：不会影响 Root 子物体，但面向只存在于画面中，读档会回到默认方向；若要持久化，还需引入独立状态和存档字段。
- 单独保存面向状态：可将视觉翻转与空间旋转分离，但当前两者都描述角色朝向，会增加同步与恢复规则。

## 影响

Root 的旋转会作用于动画、碰撞体和交互子物体。当前角色的 X 轴旋转保持为零，Y 轴用于左右面向，Z 轴可用于场景姿态；扩展旋转语义或调整子物体布局时需保持这一约定。当前接口与路线切换行为见[角色运动](../Architecture/Movement.md)。
