# 剧情资源异步预加载，同步启动并用 Token 管理文本源

NPC 对话需要在交互时立即发起，原有播放入口内部异步准备脚本与文本，使资源等待和播放生命周期交织。决定保留加载阶段的异步预加载，将脚本编译结果与已解析的当前语言文本缓存下来，播放时同步创建协程、激活文本源并启动 Player；未预加载的剧情仍可同步加载。文本源激活返回只属于本次激活的 Token，由播放所有者在收尾时取消，避免旧播放清理误解除新文本源，同时保持缓存与当前激活的生命周期独立。

现行接口、所有权及清理约束见 [Sequence 框架](../Architecture/Sequence.md)，同步加载的后端限制见 [IAssetService](../Architecture/AssetService.md)。语言设置继续遵循 [ADR-0017](0017-synchronous-language-switch-command.md) 的同步 Command 编排。

## 备选方案

- 保持播放时异步准备：能够避免未缓存读取阻塞主线程，但需要继续维护播放加载取消、旧请求身份及协程交接；当前以场景预加载消除常用对话的读取成本，优先简化播放入口，实际卡顿影响体验时再评估异步。
- 仅允许播放预加载内容：能够约束缓存命中，但要求临时剧情和独立调用方都参与预加载协议；保留未命中时同步加载，普通播放不自动扩大缓存。
- 继续无条件清除当前文本源：接口较少，但无法表达是哪次播放持有文本源；采用激活 Token，使默认、重复和过期取消无效果，且不恢复旧激活或删除预加载缓存。

## 影响

- 同步仅覆盖启动，View 准备、对白、等待与动画仍由现有 Player 生命周期和 Tick 推进。
- 信任正式启动和场景加载顺序：预加载完成后才播放或切换语言，不为预加载期间切语言增加并发协议；异步预加载仍保留生命周期取消、失败释放和清理后禁止旧结果回写的保护。
- 切换语言同步重载全部预加载目录及当前文本源，当前激活 Token 保持有效，Lua 缓存不变；未缓存读取及低频语言切换允许承担同步停顿。
- 文本源 Token 是普通只读结构体，只管理本次激活所有权，不实现 `Aoiro.ICancelToken`，不接入通用取消托管。离场、流程退出、演出表重载及 Shutdown 继续由现有所有者统一收束播放和两类缓存。
