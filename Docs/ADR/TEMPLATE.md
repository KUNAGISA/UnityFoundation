# ADR 模板

只有一项决策同时满足以下条件时才创建 ADR：改变决定的代价明显；未来维护者缺少背景时会质疑该选择；当时存在多个合理方案并进行了真实取舍。

文件名使用 `NNNN-kebab-case-slug.md`。创建前扫描本目录的最高编号并递增，不复用已经废弃的编号。ADR 记录决策及原因，不充当现行接口说明或操作手册；现行规则应链接到 `Docs/Architecture` 中的对应文档。

状态只能使用 `proposed`、`accepted`、`deprecated` 或 `superseded by ADR-NNNN`。

复制以下内容创建新 ADR：

```md
---
status: proposed
---

# <决策标题>

<用 1～3 句话说明背景、最终决定和选择原因。>

## 备选方案

<仅在被否决方案值得保留时列出；否则删除本节。>

## 影响

<仅记录不明显的代价、限制或后续约束；否则删除本节。>
```
